
# 要件定義書

## 1. 要件まとめ

- **ユーザー像・利用シーン**  
  - 営業経験が浅い「レディ」が営業先で使う  
  - 対応デバイスは PC（MVPフェーズでは PC 向け画面のみ開発）

- **AIコンサルタント一覧表示**  
  - 管理画面は後回し。ユーザーには固定リストを一覧で見せる  
  - 各コンサルタントに以下情報をあらかじめ設定  
    - 写真／名前／経歴  
    - 得意分野（業界・会社規模感）  
    - 保有人脈・紹介可能人脈  
  - ユーザーは一覧からクリックで選択。検索・絞り込み機能は不要

- **対話の振る舞い（占い師要素）**  
  1. 質問フェーズ（4〜5問）  
     - 例：  
       1. 「本日はどのようなお悩みでしょうか？」  
       2. 「現在担当されている業界について教えていただけますか？」  
       3. 「これまでのご経験で不安に思われたことはありますか？」  
       4. 「理想の提案相手に求めるポイントは何ですか？」  
       5. 「最も重視される成果指標は何でしょう？」  
  2. ホットリーディング（肯定）  
     - 例：「なるほど、その点は本当にお詳しいですね」「知らなかっただけですよね、安心してください」  
  3. コールドリーディング（本質的示唆）  
     - 例：「ただ、◯◯業界では□□の対応がカギになりますので、ぜひご留意ください」  
  4. 人材紹介提示（カード形式）

- **アウトプット形式**  
  - “最適な人材紹介” はカード形式  
  - 各カードに：名前／スキルセット／できること（紹介コメントなど）

- **会話履歴の参照**  
  - 過去の相談内容・推薦履歴をユーザー側で閲覧可能に

- **ログインフロー（MVP）**  
  - 画面は簡易版でOK。バックエンド実装は不要  
  - ユーザー登録→ログイン画面のみ用意

- **UIデザイン**  
  - ビジネス寄りの“信頼感”重視  
  - 配色：青系グラデーション ＋ 背景白  
  - アバター：リアル寄り

- **音声 I/O（MVP会話例定義）**  
  - 入力：音声認識でユーザー発話を取得  
  - 出力：AIコンサルタント応答を音声で再生  
  - 想定会話フロー例：  
    1. 質問フェーズ（音声）  
    2. ホットリーディング  
    3. コールドリーディング  
    4. 人材紹介

- **KPI**  
  - 案件成約率

## 2. 画面一覧と目的

| 画面名                     | URL パス               | 目的                                   |
|----------------------------|-----------------------|----------------------------------------|
| ログイン画面               | `/login`              | ユーザー認証（MVPは画面のみ）            |
| コンサルタント一覧画面     | `/consultants`        | 登録済みコンサルタントをカード一覧で選択 |
| コンサルタント詳細・チャット画面 | `/consultants/:id`    | 質問 → ホット/コールド → 人材紹介を実施 |
| 会話履歴画面               | `/history`            | 過去の相談内容と推薦結果を振り返り       |

## 3. 各画面の詳細仕様

### 3.1 ログイン画面

**URL**：`/login`  
**目的**：MVPの識別用画面。実際の認証ロジックは不要  

**構成要素**：  
- ロゴ＋サービス名  
- メールアドレス入力フィールド  
- パスワード入力フィールド  
- [ログイン]ボタン  
- 新規登録リンク（非アクティブ）

**遷移**：ログインボタン押下 → `/consultants`

### 3.2 コンサルタント一覧画面

**URL**：`/consultants`  
**目的**：固定リストからAIコンサルタントを選択  

**レイアウト**：  
- ページタイトル  
- カードグリッド（2〜3列）

**カード要素**：  
- アバター画像  
- 名前  
- 得意分野  
- [相談する]ボタン

**操作**：相談するボタン → `/consultants/:id`

### 3.3 コンサルタント詳細・チャット画面

**URL**：`/consultants/:id`  
**目的**：ヒアリング→アドバイス→人材紹介

**上部：コンサルタント情報**  
- アバター＋名前＋経歴＋得意分野＋人脈概要

**中央：会話エリア**  
- 質問フェーズ（4〜5問の自動質問）  
- ホットリーディング→コールドリーディング応答  
- 人材紹介フェーズ（カード形式）

**下部：入力エリア**  
- 音声入力マイクアイコン  
- テキスト入力フィールド  
- 送信ボタン

### 3.4 会話履歴画面

**URL**：`/history`  
**目的**：過去の相談内容と推薦結果を参照

**レイアウト**：  
- 一覧表示（カード/テーブル）  
- 詳細モーダル or 個別画面

**詳細表示**：  
- 会話全文＋音声再生  
- 紹介人材カード
